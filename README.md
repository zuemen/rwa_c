# RWA Realty Capital

一個更專業的 React 房地產 RWA 概念網站，靈感來自 RealT / Homebase，但加強成更接近正式產品提案的版本。

## 這版新增重點

- 更機構化的品牌與資產池敘事
- 錢包連接能力（EIP-1193 / MetaMask 類錢包）
- 臺灣法遵導向內容：STO / AML / 真名制 / 風險揭露設計方向
- ERC-3643、ERC-1400、ERC-1155、ERC-20 的兩層式合約策略
- 研究導向的產品定位與 roadmap

## Run locally

```bash
python3 -m http.server 4173
```

打開 <http://localhost:4173>。

## Contract direction

- **Primary issuance / compliance:** ERC-3643
- **Structured security rights:** ERC-1400
- **Portfolio share layer:** ERC-1155
- **Utility / rewards layer:** ERC-20

## Important note

本專案中的臺灣法規內容屬於產品設計與法遵準備方向，不構成正式法律意見。正式發行前應由臺灣律師、券商、會計師與資安顧問進一步確認。
